## 발견사항

### [관찰] Date 입력 필드 자동화 우회 필요

- React controlled `<input type="date">` 필드는 `fill` 명령어만으로 React state 업데이트 불가
- `native value setter + input 이벤트 dispatch` 방식으로 우회 가능
- 실제 사용자 UX에는 영향 없음

### [관찰] React controlled input 카운터 갱신 지연

- SC-10에서 `fill` 명령어로 입력 시 카운터가 React state 기준으로 갱신되지 않는 경우 있음
- `native value setter` 방식 사용 시 정상 갱신 확인
- 실제 사용자 UX에는 영향 없음

### [관찰] 카테고리 삭제 후 할일 카드 미지정 전환 시 페이지 새로고침 필요

- SC-07에서 `임시` 카테고리 삭제 후 할일 카드에 즉시 `미지정` 반영되지 않음
- 페이지 새로고침 후 정상 반영 확인
- React Query 캐시 invalidation 범위 개선 권장 (우선순위 낮음)
