## 2. 발견 사항 (Findings)

### [BUG] 기한 초과 필터 버튼 `active` 상태 비일관성 (SC-06 과정 중 발견)

- **현상:** "기한 초과" 필터 활성화(`isOverdueOnly=true`) 후 다른 상태 탭(전체)으로 전환하면, 내부 Zustand 상태는 `isOverdueOnly=true`를 유지하나 버튼의 `[active]` 시각 표시가 사라짐.
- **영향:** 사용자가 기한 초과 필터가 해제되었다고 오해할 수 있음. 목록이 빈 상태로 보여도 원인을 직관적으로 파악하기 어려움.
- **재현 조건:** 기한 초과 필터 ON → 완료/진행중 탭 전환 → 전체 탭으로 복귀 시.
- **권고:** 상태 탭 전환 시 `isOverdueOnly`를 `false`로 자동 초기화하거나, 탭 전환과 무관하게 버튼 `[active]` 시각 상태를 스토어와 동기화.

### [관찰] SC-11 한도 초과 안내 문구 미노출 (이전 결과와 동일)

- 카테고리 20개 한도 도달 시 추가 버튼/입력 필드 비활성화는 정상 동작하나, 별도 안내 문구("카테고리는 최대 20개까지 생성할 수 있습니다." 등)는 표시되지 않음.
- "카테고리 20 / 20" 카운터로 상태를 유추할 수 있으나, 명시적 안내 문구 추가 권고.

### [관찰] Playwright `browser_fill_form` 한국어 IME 처리 문제

- 테스트 도구 수준의 이슈로 앱 버그는 아님.
- `browser_fill_form`의 유니코드 이스케이프 처리 과정에서 `낙`(낙)와 `납`(납)이 혼동되는 현상 발생 → "도서관 반납" 대신 "도서관 반낙"으로 입력됨.
- SC-07 카테고리 삭제 후 미지정 전환 동작 자체는 정상 확인.
