## 1. 와이어프레임 개요

TodoList는 인증된 개인 사용자가 카테고리 기반으로 할일을 관리하는 반응형 웹 애플리케이션이다. 화면 구조는 `할일 목록 화면(SCR-03)`을 중심 허브로 두고, 회원가입/로그인, 할일 등록/상세/수정, 카테고리 관리, 사용자 정보 화면을 연결한다.

### 1.1 설계 원칙

- 목록 중심 CRUD 앱으로 설계한다.
- 모바일은 단일 컬럼, 데스크톱은 필터/목록/상세를 분리한 2~3영역 배치를 사용한다.
- Todo/Category/User 서버 데이터는 TanStack Query가 관리한다.
- Zustand는 선택된 카테고리, 상태 탭, overdue 필터, 모달 열림 여부 같은 UI 상태만 관리한다.
- 입력 오류는 인라인 메시지로 즉시 표시한다.
- 모든 API 요청에는 로딩, 오류, 재시도 또는 복구 동선을 제공한다.
- Phase 1 제외 범위인 알림, 파일 첨부, 협업, 외부 캘린더 연동, 통계 대시보드, 소셜 로그인은 포함하지 않는다.
- 다크모드, 다국어 UI, 내부 캘린더 모드는 추가 개선 범위로 반영한다.

### 1.2 화면 목록

| 화면 ID | 화면명 | 목적 | 진입/연결 |
|---------|--------|------|-----------|
| SCR-01 | 회원가입 화면 | 이메일/비밀번호 기반 계정 생성 | SCR-02 회원가입 링크 |
| SCR-02 | 로그인 화면 | 인증 세션 획득 | 최초 진입, 로그아웃 후, 미인증 접근 시 |
| SCR-03 | 할일 목록 화면 | 본인 할일 조회, 필터링, 상태 변경 | 로그인 성공 후 기본 화면 |
| SCR-04 | 할일 등록 화면 | 새 할일 생성 | SCR-03 할일 추가 |
| SCR-05 | 할일 상세/수정 화면 | 상세 확인, 수정, 삭제, 상태 변경 | SCR-03 Todo 항목 선택 |
| SCR-06 | 카테고리 관리 화면 | 카테고리 추가, 수정, 삭제 | SCR-03 카테고리 관리 |
| SCR-07 | 사용자 정보 화면 | 본인 계정 정보 확인, 로그아웃 | SCR-03 계정 메뉴 |

## 2. 화면 전환 흐름

```text
[미인증 진입]
  |
  v
SCR-02 로그인
  | 회원가입
  v
SCR-01 회원가입
  | 성공
  v
SCR-02 로그인
  | 로그인 성공
  v
SCR-03 할일 목록
  |-- 할일 추가 --------> SCR-04 할일 등록 -- 저장/취소 --> SCR-03
  |-- Todo 선택 --------> SCR-05 상세/수정 -- 저장/삭제/닫기 --> SCR-03
  |-- 카테고리 관리 ----> SCR-06 카테고리 관리 -- 닫기 --> SCR-03
  |-- 사용자 정보 ------> SCR-07 사용자 정보 -- 로그아웃 --> SCR-02
```

## 3. 공통 레이아웃 규칙

### 3.1 모바일 기본 배치

```text
┌──────────────────────────────┐
│ Header: TodoList / 계정       │
├──────────────────────────────┤
│ 주요 액션                     │
│ [할일 추가] [카테고리]        │
├──────────────────────────────┤
│ 필터 칩/탭                    │
│ [전체] [업무] [개인] [...]    │
│ [전체|진행 중|완료] [기한초과]│
├──────────────────────────────┤
│ Todo 카드 목록                │
│ ┌──────────────────────────┐ │
│ │ □ 제목                   │ │
│ │ 설명 요약                │ │
│ │ 카테고리 / 종료일 / 상태 │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

- 320px 이상에서 단일 컬럼으로 표시한다.
- 카테고리 필터는 가로 스크롤 칩 또는 접을 수 있는 필터 영역으로 배치한다.
- Todo 항목은 카드형 세로 목록으로 표시한다.
- 모달은 모바일에서 바텀시트 또는 전체 화면에 가까운 형태로 표시한다.

### 3.2 데스크톱 기본 배치

```text
┌──────────────────────────────────────────────────────────────┐
│ Header: TodoList                         사용자 / 로그아웃   │
├───────────────┬──────────────────────────┬───────────────────┤
│ Category      │ Todo List                │ Detail Panel       │
│ - 전체        │ [상태 탭] [기한초과]     │ 선택 Todo 상세     │
│ - 업무        │ [할일 추가]              │ 또는 안내/빈 상태  │
│ - 개인        │ ┌──────────────────────┐ │                   │
│ [관리]        │ │ Todo row/card        │ │                   │
│               │ └──────────────────────┘ │                   │
└───────────────┴──────────────────────────┴───────────────────┘
```

- 1280px 이상에서는 좌측 필터, 중앙 목록, 우측 상세 패널 구성을 권장한다.
- 할일 등록과 카테고리 관리는 모달 또는 우측 패널로 열 수 있다.
- 필터 변경, 상태 변경, 생성/수정/삭제 후 목록을 즉시 갱신한다.

### 4.4 SCR-04 할일 등록 화면

목록 중심 앱이므로 기본 와이어프레임은 모달로 정의한다. 모바일에서는 전체 화면 또는 바텀시트 형태를 허용한다.

```text
┌──────────────────────────────┐
│ 새 할일 추가              X  │
├──────────────────────────────┤
│ 제목 *                       │
│ [ 주간 보고서 작성        ]  │
│ 9 / 100                      │
│ (제목 오류 영역)             │
│                              │
│ 설명                         │
│ [ 상세 설명 입력          ]  │
│                              │
│ 종료일                       │
│ [ 2026-04-29             ]  │
│                              │
│ 카테고리                     │
│ [ 업무 v                  ]  │
│ 옵션: 미지정 허용            │
├──────────────────────────────┤
│ [취소]              [저장]   │
└──────────────────────────────┘
```

핵심 UI:
- 제목 입력, 필수, 최대 100자
- 제목 글자 수
- 설명 입력, 선택
- 종료일 입력, 선택
- 카테고리 선택, 선택, 미지정 허용
- 저장/취소 버튼

상태:
- 제목 빈값 오류
- 제목 100자 초과 오류
- 카테고리 목록 로딩
- 카테고리 없음: 드롭다운에 미지정만 표시
- 저장 중: 저장 버튼 로딩 및 중복 제출 방지
- 저장 실패: 폼 상단 또는 버튼 근처 오류 표시
- 성공: 모달 닫기, SCR-03 목록 갱신

컴포넌트 후보:
- `TodoCreateModal`
- `TodoForm`
- `CategorySelect`
- `InlineError`

### 4.5 SCR-05 할일 상세/수정 화면

데스크톱은 우측 패널, 모바일은 전체 화면 모달을 권장한다.

```text
┌──────────────────────────────┐
│ 할일 상세/수정            X  │
├──────────────────────────────┤
│ 상태                         │
│ [진행 중] [완료로 변경]      │
│ 기한 초과 배지 영역          │
│                              │
│ 제목 *                       │
│ [ 분기 보고서 제출        ]  │
│ 9 / 100                      │
│                              │
│ 설명                         │
│ [ 상세 설명               ]  │
│                              │
│ 종료일                       │
│ [ 2026-04-30             ]  │
│                              │
│ 카테고리                     │
│ [ 업무 v                  ]  │
│                              │
│ 생성일: 2026-04-28           │
│ 완료일: -                    │
├──────────────────────────────┤
│ [삭제] [취소]        [저장]  │
└──────────────────────────────┘
```

삭제 확인:

```text
┌──────────────────────────────┐
│ 할일을 삭제할까요?           │
│ 삭제한 할일은 목록에서 제거됩니다. │
│ [취소]              [삭제]   │
└──────────────────────────────┘
```

핵심 UI:
- 상태 표시 및 상태 변경
- 제목, 설명, 종료일, 카테고리 수정
- 생성일시, 완료일시 표시
- 기한 초과 배지
- 저장, 삭제, 취소/닫기 버튼
- 삭제 확인 다이얼로그

상태:
- 수정 중, 삭제 중, 상태 변경 중 로딩
- 제목 빈값/100자 초과 오류
- 403 권한 없음
- 404 대상 없음
- 완료 전환 시 완료일시 표시
- 진행 중 복귀 시 완료일시 제거 및 overdue 재판단
- 성공 시 SCR-03 목록 갱신

컴포넌트 후보:
- `TodoDetailModal`
- `TodoForm`
- `TodoStatusControl`
- `DeleteConfirmDialog`
- `ErrorBanner`

### 4.6 SCR-06 카테고리 관리 화면

```text
┌──────────────────────────────┐
│ 카테고리 관리             X  │
├──────────────────────────────┤
│ 카테고리 2 / 20              │
│ [ 새 카테고리 이름       ]   │
│ 0 / 20                       │
│ [추가]                       │
│ (중복/길이/한도 오류 영역)   │
├──────────────────────────────┤
│ 카테고리 목록                │
│ ┌──────────────────────────┐ │
│ │ 업무          [수정][삭제]│ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ 개인          [수정][삭제]│ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

인라인 수정:

```text
┌──────────────────────────────┐
│ [ 업무 수정명           ]    │
│ 5 / 20                       │
│ [취소] [저장]                │
└──────────────────────────────┘
```

삭제 확인:

```text
┌──────────────────────────────┐
│ 카테고리를 삭제할까요?       │
│ 소속 Todo는 삭제되지 않고    │
│ 미분류로 전환됩니다.         │
│ [취소]              [삭제]   │
└──────────────────────────────┘
```

핵심 UI:
- 현재 카테고리 수와 최대 20개 한도 표시
- 카테고리 이름 입력, 최대 20자
- 추가 버튼
- 카테고리 목록
- 수정 버튼
- 삭제 버튼
- 삭제 확인 다이얼로그

상태:
- 빈 상태: "아직 카테고리가 없습니다."
- 목록 로딩
- 목록 조회 실패 + 재시도
- 이름 필수/20자 초과 오류
- 중복 이름 오류
- 20개 도달 시 추가 버튼 비활성화 또는 한도 안내
- 추가/수정/삭제 중 버튼 로딩
- 삭제 성공 후 SCR-03 필터와 Todo 목록 갱신

컴포넌트 후보:
- `CategoryManageModal`
- `CategoryForm`
- `CategoryList`
- `CategoryItem`
- `DeleteConfirmDialog`

## 5. 상태 및 오류 와이어프레임

### 5.1 Todo 목록 상태

```text
전체 빈 상태:
┌──────────────────────────────┐
│ 아직 등록된 Todo가 없습니다. │
│ [할일 추가]                  │
└──────────────────────────────┘

필터 결과 없음:
┌──────────────────────────────┐
│ 조건에 맞는 Todo가 없습니다. │
│ [필터 초기화]                │
└──────────────────────────────┘

조회 실패:
┌──────────────────────────────┐
│ Todo 목록을 불러오지 못했습니다. │
│ [다시 시도]                  │
└──────────────────────────────┘
```

### 5.2 입력 검증 상태

| 입력 | 검증 | UI 표시 |
|------|------|---------|
| 이메일 | 필수, 이메일 형식 | 필드 하단 인라인 오류 |
| 비밀번호 | 필수, 정책 확정 필요 | 필드 하단 정책 안내/오류 |
| Todo 제목 | 필수, 최대 100자 | 글자 수와 인라인 오류 |
| Category 이름 | 필수, 최대 20자 | 글자 수와 인라인 오류 |
| Category 수 | 최대 20개 | 한도 안내, 추가 버튼 비활성화 |

### 5.3 인증/권한 오류

| 상황 | 처리 |
|------|------|
| 401 인증 없음/만료 | 토큰 제거 후 SCR-02 로그인 이동 |
| 403 권한 없음 | 상세/수정 화면에 권한 오류 표시 |
| 404 대상 없음 | 상세/수정 화면에 대상 없음 오류 표시 후 목록 복귀 동선 제공 |
| 서버 오류 | 화면 상단 배너 또는 폼 메시지로 표시 |

## 6. 주요 사용자 흐름별 와이어프레임 체크

### 6.1 회원가입

- [ ] SCR-02에서 SCR-01로 이동할 수 있다.
- [ ] 이메일/비밀번호 입력이 가능하다.
- [ ] 이메일 형식 오류가 인라인으로 표시된다.
- [ ] 중복 이메일 오류가 표시된다.
- [ ] 성공 후 SCR-02로 이동한다.

### 6.2 로그인/로그아웃

- [ ] SCR-02에서 로그인할 수 있다.
- [ ] 성공 시 SCR-03으로 이동한다.
- [ ] 인증 실패 메시지가 표시된다.
- [ ] SCR-07 또는 계정 메뉴에서 로그아웃할 수 있다.
- [ ] 로그아웃 후 SCR-02로 이동한다.

### 6.3 Todo 생성/수정/삭제

- [ ] SCR-03에서 SCR-04를 열 수 있다.
- [ ] 제목/설명/종료일/카테고리 입력이 가능하다.
- [ ] 제목 빈값/100자 초과가 인라인으로 표시된다.
- [ ] 카테고리 없이 Todo를 생성할 수 있다.
- [ ] SCR-05에서 Todo를 수정할 수 있다.
- [ ] SCR-05에서 삭제 확인 후 Todo를 삭제할 수 있다.

### 6.4 상태 변경/기한 초과

- [ ] SCR-03 또는 SCR-05에서 진행 중 Todo를 완료로 변경할 수 있다.
- [ ] 완료 Todo에는 완료일시가 표시된다.
- [ ] 완료 Todo는 기한 초과로 표시되지 않는다.
- [ ] 완료 Todo를 진행 중으로 되돌릴 수 있다.
- [ ] 진행 중이면서 종료일이 오늘 이전인 Todo는 기한 초과로 표시된다.

### 6.5 카테고리 관리

- [ ] SCR-03에서 SCR-06을 열 수 있다.
- [ ] Category를 생성할 수 있다.
- [ ] Category 이름 20자 초과 오류가 표시된다.
- [ ] 중복 이름 오류가 표시된다.
- [ ] 20개 한도 도달 시 추가 제한이 표시된다.
- [ ] Category를 수정할 수 있다.
- [ ] Category 삭제 시 소속 Todo 미분류 전환 안내가 표시된다.
- [ ] 삭제 후 필터/선택 목록에서 해당 Category가 제거된다.

### 6.6 필터링

- [ ] 카테고리 필터를 선택할 수 있다.
- [ ] 상태 탭을 선택할 수 있다.
- [ ] 기한 초과 필터를 선택할 수 있다.
- [ ] 필터 초기화를 할 수 있다.
- [ ] 필터 결과 없음과 전체 빈 상태가 구분된다.
