## 1. 제품 개요

### 1.1 목적

TodoList는 개인 사용자가 할일을 카테고리 기반으로 체계적으로 관리할 수 있도록 설계된 웹 애플리케이션이다. 인증된 사용자에게 할일 등록/수정/삭제, 상태 추적, 기한 초과 감지, 카테고리 분류 기능을 제공한다.

### 1.2 배경

기존 일정 관리 도구는 카테고리 분류 체계가 미흡하고 기한 초과 상태를 명확히 표현하지 못하는 한계가 있다. 이를 해소하기 위해 카테고리 기반 분류와 기한 초과 필터링을 핵심 기능으로 채택한다.

### 1.3 핵심 가치

- **개인 데이터 격리:** 모든 데이터는 인증된 사용자 단위로 완전히 격리된다.
- **카테고리 분류:** 사용자 정의 카테고리로 할일을 체계적으로 관리한다.
- **기한 초과 가시화:** 완료되지 않은 기한 초과 할일을 즉각적으로 식별할 수 있다.
- **반응형 접근성:** 모바일과 데스크탑 모두에서 일관된 사용 경험을 제공한다.

## 2. 사용자 페르소나

## 3. 기능 범위

### Phase 1 (2026-04-28 ~ 2026-04-30)

**In-scope**

| 영역 | 기능 |
|------|------|
| 사용자 인증 | 회원가입, 로그인, 로그아웃 |
| 할일 관리 | 할일 등록/조회/수정/삭제, 상태 변경, 기한 초과 조회 |
| 카테고리 관리 | 카테고리 추가/수정/삭제, 카테고리 기준 필터링 |
| 사용자 정보 관리 | 본인 계정 정보 조회 |

**Out-of-scope (Phase 1 제외)**

- 팀 협업 및 할일 공유
- 외부 캘린더(Google Calendar 등) 연동
- 알림 / 푸시 알림
- 파일 첨부
- 다크모드 (Phase 2)
- 다국어 지원 (Phase 2)
- 통계 및 리포트 대시보드
- 소셜 로그인

### Phase 2 (일정 미정)

- 다크모드 UI
- 다국어 지원 (i18n)

## 9. 가정 및 제약사항

### 가정

- 사용자는 최신 버전의 Chrome, Safari, Edge 브라우저를 사용한다고 가정한다.
- 서비스는 단일 사용자 단위로만 운영되며 팀/조직 단위 기능은 없다.
- 기한 초과 판단 기준은 서버 시스템 날짜(UTC 기준)를 사용한다.
- Phase 1 기간 동안 사용자 규모는 소규모(동시 접속 수십 명 이내)를 가정한다.

### 제약사항

- TypeScript를 사용하지 않는다. (프론트엔드/백엔드 모두 JavaScript)
- JWT 알고리즘은 HS-512로 고정한다.
- 카테고리는 사용자당 최대 20개로 제한한다.
- 할일 제목은 최대 100자, 카테고리 이름은 최대 20자로 제한한다.
- Phase 1에서 다크모드 및 다국어 지원은 구현하지 않는다.
